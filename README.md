# Анализ файловой системы

Лабораторная работа по компонентному веб-программированию.
Автор: Дмитрий Камышников, ИСУ 312519.

Приложение на Node.js обходит `/data` и выводит одну строку:

```text
312519-FILES-DIRECTORIES-SIZE
```

Учитываются обычные файлы и вложенные каталоги, включая пустые.
Размер считается в байтах. Сам `/data`, символические ссылки и специальные
файлы не учитываются. Входные данные не изменяются.

## Сборка и запуск

```bash
docker build -t student-fs .
docker run --rm --network none \
  --mount type=bind,source="$(pwd)/test-data",target=/data,readonly \
  student-fs
```

`test-data` должен существовать перед запуском.

## Проверка

На Linux с Docker и Node.js:

```bash
node test.mjs student-fs
```

Проверяются пустой каталог, обычные и пустые файлы, пустые каталоги,
вложенность, пробелы и кириллица в именах, скрытые и двоичные файлы,
ссылки и специальный файл FIFO. Каждый контейнер запускается без сети
и с каталогом `/data` только для чтения.
